# browser-world

브라우저에서 돌아가는 나만의 작은 세계.
픽셀 아트 생명체들이 살고, 먹고, 번식하고, 진화하는 시뮬레이션.

## 실행

```bash
npm i
npm run dev
```

## 스택

Vite · React · TypeScript · Tailwind v4 — 시뮬레이션 로직(`src/sim/`)은 순수 TS, React는 HUD/패널만 담당.

## 현재 규칙

- 생명체는 시야 안 가장 가까운 먹이로 이동, 없으면 랜덤 배회
- 유전자: 속도 · 크기 · 시야 · 색. 크고 빠르고 시야 넓으면 대사 비용 ↑
- 에너지 120 넘으면 번식 (±12% 돌연변이)
- 클릭하면 스탯 + 족보(죽은 조상은 † 표시)
